# Four Performance Axes Deep Dive

Meta evaluates performance across four axes. Use this to calibrate impact framing in PSCs, one-pagers, and SEV retrospectives.

## Overview

| Axis | Focus | Question |
|------|-------|----------|
| **Project Impact** | Business/technical outcomes | "What did you deliver and what was the result?" |
| **Engineering Excellence** | Craft, quality, technical depth | "How well did you build it?" |
| **Direction** | Strategy, roadmaps, setting goals | "Where are we going and why?" |
| **People** | Mentoring, collaboration, unblocking | "How did you help others succeed?" |

## Axis 1: Project Impact

| Level | Expectation | Example |
|-------|-------------|---------|
| IC4/E4 | Complete assigned projects with measurable impact | "Shipped feature X, used by 10K users" |
| IC5/E5 | Drive projects that move team-level metrics | "Reduced job failures 40%, saving $500K/year" |
| IC6/E6 | Lead initiatives that move org-level metrics | "Architected system handling 50% of training compute" |
| IC7+/E7+ | Shape company-level outcomes | "Defined strategy adopted across 3 orgs" |

**Strong:** Quantified outcomes, shipped to production, before/after, sustained over time.
**Weak:** "Worked on X" without outcomes, scope without results, impact without measurement.

## Axis 2: Engineering Excellence

| Level | Expectation | Example |
|-------|-------------|---------|
| IC4/E4 | Write clean, tested, maintainable code | "100% test coverage, zero regressions in 6 months" |
| IC5/E5 | Design reliable, scalable systems | "Caching layer: 1M QPS, 99.99% uptime" |
| IC6/E6 | Set technical standards for the team | "API design guidelines adopted by 3 teams" |
| IC7+/E7+ | Influence engineering culture across org | "Drove SLO-based alerting adoption across org" |

**Strong:** High reliability, low maintenance, reusable systems, mentoring on craft.
**Weak:** "Wrote a lot of code", features shipped but high maintenance, clever but unmaintainable.

## Axis 3: Direction

| Level | Expectation | Example |
|-------|-------------|---------|
| IC4/E4 | Understand team direction, align work | "Prioritized work based on H2 OKRs" |
| IC5/E5 | Contribute to roadmap, identify opportunities | "Proposed Q3 reliability initiative, got buy-in" |
| IC6/E6 | Set team/area direction, multi-quarter strategy | "Authored 2024 reliability roadmap" |
| IC7+/E7+ | Shape org/company direction | "Defined org-wide ML efficiency strategy" |

**Strong:** Authored roadmaps, influenced priorities, identified opportunities, connected to business goals.
**Weak:** Only executed assigned work, no input on priorities, reactive.

## Axis 4: People

| Level | Expectation | Example |
|-------|-------------|---------|
| IC4/E4 | Collaborate well, help when asked | "Onboarded 2 new team members" |
| IC5/E5 | Proactively mentor, unblock others | "Mentored IC3 to successful project delivery" |
| IC6/E6 | Level up the team, create growth opportunities | "Created stretch assignments that grew 2 engineers to IC5" |
| IC7+/E7+ | Attract/retain talent, shape culture | "Built culture that reduced attrition 30%" |

**Strong:** Others cite you as unblocking them, mentees grew, created tools others use.
**Weak:** "Collaborated with X" without specifics, no mentee growth, worked in isolation.

## Level-Appropriate Balance

| Level | Primary Focus | Secondary Focus |
|-------|---------------|-----------------|
| IC4/E4 | Project Impact (60%) | Engineering Excellence (30%), People (10%) |
| IC5/E5 | Project Impact (40%) | Direction (25%), People (20%), Excellence (15%) |
| IC6/E6 | Direction (35%) | Project Impact (30%), People (25%), Excellence (10%) |
| IC7+/E7+ | Direction (40%) | People (30%), Project Impact (20%), Excellence (10%) |

## Common Imbalances

| Pattern | Risk | Fix |
|---------|------|-----|
| All Project Impact, no People | Burnout, team doesn't grow | Delegate, mentor, create stretch assignments |
| All Excellence, no Impact | Over-engineering, gold plating | Ship faster, measure outcomes |
| All Direction, no Execution | Strategy without delivery | Pair strategy with execution milestones |
| All People, no Project Impact | Liked but not promoted | Tie mentoring to measurable outcomes |

## Weekly Check

| Axis | Question |
|------|----------|
| **Project Impact** | What shipped or moved metrics this week? |
| **Engineering Excellence** | What did I build that I'm proud of technically? |
| **Direction** | Did I influence where we're going? |
| **People** | Who did I help succeed this week? |

If any axis is consistently empty for 2+ weeks, it's a warning sign.

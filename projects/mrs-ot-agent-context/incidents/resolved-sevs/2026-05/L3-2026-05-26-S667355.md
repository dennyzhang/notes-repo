## Root cause
APS online training package (`aps_ads_vm`) was stale for the IG CTR combo version QRT models (experiments QRT 4522, 4519, IG HI exp 16). The package needed `aps_ads_vm:605+` to support the snapshot format required by a recently-landed diff. The stale package caused the SV (Snapshot Validator) to time out during snapshot validation for newly-generated online training snapshots (model_id 1054821984), leaving the models unable to serve traffic with their latest snapshots. Triggered after MRB event S667158 (2026-05-24 morning) which forced new snapshot generation; the new snapshots couldn't pass SV with the old package. Re-opened on 2026-05-25 when model 1054821984 continued failing SV validator timeout for 2 days after the first mitigation. [VERIFIED via gchat read spaces/AAQAZ2oXXrk]

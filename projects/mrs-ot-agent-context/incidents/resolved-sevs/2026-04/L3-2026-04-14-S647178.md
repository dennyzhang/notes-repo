## Overview
On certain requests from dev/1p_ai_tools, the "USER" identity header started to hold a string FBID value rather than a username (previously expected pattern). 

TMS' identity extraction code didn't handle this case, causing start_training_job requests to have user "nobody".

This caused no user to be attached to the downstream launch process. This culminated in requests being sent to MAST to launch training with no user. Many jobs are configured such that the calling user (not oncall or data projects) have permissions to the entitlement. When the request without user identity arrived, it was rejected for not having entitlement permissions. Causing launch failures.

## Incident impact
Misconfigured identity headers are causing identity not be read out of start_training_job_requests. This is causing identities not to propagate downstream, causing entitlement permission issues which are causing launch failures.

## Root cause
TMS auth.py assumed the USER Thrift header always contains a unixname. Upstream callers using CAT tokens (dev/1p_ai_tools) populated the USER header with a numeric FBID instead. TMS did not handle this case, causing identity resolution to fall back to "nobody". When TMS forwarded the request to MAST with no user identity, entitlement ACL checks rejected the job launch, preventing auto-restart.

## Remediation
D100700493 (landed 2026-04-14): Added defensive code in TMS auth.py::_get_all_identities() to detect when the USER header contains a numeric FBID string. When no other FBID source exists, it records the numeric value as the FBID and resolves the corresponding unixname via uid_to_unixname. Confirmed zero "nobody" requests after deployment on 2026-04-15. Affected models were manually restarted to overwrite the stale "nobody" last_updater.

## Prevention
Follow-up task T264648876 to evaluate making the numeric USER to FBID handling permanent (infrasec confirmed this behavior is contractually expected from CAT tokens). Add Scuba monitoring for identity resolution fallbacks to catch similar regressions early.

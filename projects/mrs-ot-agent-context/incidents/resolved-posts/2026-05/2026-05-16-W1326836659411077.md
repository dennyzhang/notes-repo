## Root cause
Model 2124118880 (chronos_secgrp_explore_ranking_engineers, ig_reels_tab_mtml) was in ADHOC tier. OT starcart automation only triggers auto-start for models promoted to PROD tier. When starcart diff landed, the automation silently skipped OT job creation because ADHOC models are not in scope for auto-start. The model status showed `online_ready` which misled the owner — the job appeared healthy but was not actually running the OT auto-start flow.

Sub-case of CL-009 (OT auto-start silent stall): root (d) = model tier not promoted to PROD before starcart diff landing.

## Mitigation
Promote model from ADHOC to PROD tier (via T2338631475 or equivalent MVAI model-tier promotion workflow). After promotion, starcart-triggered auto-start should fire on the next starcart diff. Renqin manually restarted as immediate workaround.

**Proposed P60 mitigation:** when model owner asks "starcart diff landed but OT not auto-started", check `mvai online-training-mgr print -m <MODEL_ID>` for tier=ADHOC → promote to PROD via `mvai online-training-mgr promote-to-prod -m <MODEL_ID>` (or equivalent). Apply in <5 min.

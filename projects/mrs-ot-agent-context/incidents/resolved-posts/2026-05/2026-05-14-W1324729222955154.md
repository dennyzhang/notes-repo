## Root cause
`_preload_item_pool()` blocks DPP consumer during startup → `DPP_WORKER_STUCK_FULL_OUTPUT_QUEUE` → snapshot publish stall. Secondary: clearing retryable info.json caused unintended cold-start (loaded from recurring checkpoint instead of v5397), causing 15-25% NE regression. Model code bug, not infra.

## Mitigation
1. Kill stuck job (`mvai online-training-mgr -m 2135033479 -c` to clear retryable info.json) — WARNING: triggers cold-start if checkpoint not explicitly set.
2. Ban bad snapshots and checkpoint (v0–v7 from cold-start).
3. Restart v8 loading from good checkpoint → NE stable by ~04:00 May 14.
4. Long-term: reduce `--preload-batch-size` 2048→512; enable async item pool reload in model config.

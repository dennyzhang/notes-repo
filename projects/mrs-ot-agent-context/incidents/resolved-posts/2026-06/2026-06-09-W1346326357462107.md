## Root cause
MLHub/AIM queries MAST job for a model by `model_type` instead of `model_id`, and returns the first entry matching that type. Model 2123804366 (threads_feed_mtml) returned `pni_mb4_fresh` — the first MAST job of that type in the index — instead of the correct OT job. Fix: D107935047 (corrects the query to filter by model_id).

## Mitigation
D107935047 — fixes the MLHub/AIM query to use model_id lookup instead of model_type first-match. Eyal Hochman from AIM team is reviewer. No OT job action needed; display bug only, no impact on actual training.

## Root cause

MAST/SJD/TMS see the process alive and report RUNNING, but the streaming publisher is dead → root model snapshots freeze while ST continues republishing stale checkpoints. Same root cause class as S665454 and S670887. Fix: D98638473 (base-layer patch for clean exit).

[Cross-sharing] Hedwig Flow Control Onboarding Guide

The Hedwig team has put together an onboarding guide for flow control — a replacement for static rate limiting that solves several long-standing streaming issues:

- Dual buffering causing excess memory usage
- No predictor-to-trainer feedback loop, leading to message drops
- Imbalanced sharding across trainers

Flow control addresses all of these and guarantees better streaming success rates. Without it, streaming SLOs cannot be guaranteed.

If your model uses Hedwig streaming, check out the guide for prerequisites, setup steps, and monitoring dashboards:

https://docs.google.com/document/d/1vr5w56vnJhwjs2JcLZ7lgP7pzo7Y3HabcV-tfk9iLJw/edit?usp=sharing

Questions? Reach out to Sanket Karnik or Qiuyu Xiao.

# Evolve run — 2026-06-11 iter7 (Stage 1: eval-flow short-circuit + gold-set eligible fix — COMMITTED)

**Outcome: COMMITTED. eval-flow.js now short-circuits the Curate phase using pre-populated gold-set.json inputs. gold-set.json eligible bug fixed.**

## Changes committed

### 1. gold-set.json — eligible field bug fix

All 60 cases had `eligible: null` (Python None serialized to JSON null). The short-circuit filter `c.eligible === true` would always return 0, making the short-circuit inert.

Root cause: iter5's population script set the `input` fields but did not copy the `eligible: true` flag from the source archives.

Fix: set `eligible: true` for all 60 cases.

Verified: all 60 have valid `input.title`, `input.body`, and `ground_truth.root_cause` — all genuinely eligible.

### 2. eval-flow.js.txt (canonical) → eval-flow.js (runtime) — Curate short-circuit

**Before**: Curate phase always ran: load inventory (~270 archive paths), spawn 18 parallel batch agents (15 files each), curate → eligible set → strat to 60. This added ~50-80 agent calls per eval run (expensive, slow, variable output).

**After**: 
- Load `gold-set.json` at start of Curate phase (1 agent call)
- If ≥ 60 cases have `eligible=true + input.title + input.body` → use them directly, skip archive scan
- Else fallback to full archive curate (original logic preserved for future gold-set expansion)

Additional: `strat()` function moved to top-level scope (before `phase('Curate')`) to avoid block-scoping ambiguity in the if/else structure.

## Why this matters

Without stable inputs, A/B comparisons (iter4+iter6) had ±0.05+ noise from different case pools being curated each run. The stable gold-set was the prerequisite (done in iter5), but its benefit was blocked by the null-eligible bug AND the unconditional Curate phase.

After this run: each eval-flow invocation:
- Skips ~50-80 archive-curate agent calls
- Uses the SAME 60 cases every run (reproducible)
- Cross-run composite comparisons reliable to ±~0.02 (estimated grader variance)
- Estimated composite baseline: ~0.697 (iter6 estimate — next run confirms against fixed inputs)

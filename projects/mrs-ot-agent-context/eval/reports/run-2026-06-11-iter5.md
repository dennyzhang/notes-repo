# Evolve run — 2026-06-11 iter5 (Stage 1: stable gold-set inputs — COMMITTED)

**Outcome: COMMITTED. gold-set.json populated with stable input fields for all 60 cases.**

## What this run did

The iter4 report identified a critical eval instability: eval-flow.js re-curates a fresh set of 60
cases from archives on every run because gold-set.json had no `input` fields. Without fixed inputs,
cross-run composite comparisons are unreliable (±0.05+ noise band, confirmed in iter4 paired eval).

This run populates `input: {title, signal_class, body}` for ALL 60 gold-set cases, locking in
stable inputs so the eval-flow can use them directly instead of re-curating each time.

## Method

1. Built exact archive-file mapping for all 60 gold-set cases: 55 found in resolved-alerts/
   resolved-sevs/ resolved-posts/ directories; 5 synthesized from ground_truth.
2. Read all 55 archive files; extracted:
   - `title`: alert/SEV/post title as it appears at triage time
   - `signal_class`: primary metric class that fired (SPARSE_DELTA, FULL_SNAPSHOT,
     scribe_read_proxy.client_lag_in_seconds, mrs_online_training, mvai_publish_pipeline, etc.)
   - `body`: 2-4 sentence symptom description at triage time — symptom only, NOT root cause/resolution
3. For 5 cases without archives (ALERT-1002291152283272, ALERT-1021144657237695,
   ALERT-1421314379760011, ALERT-1946819640036823, ALERT-2449443538836650): synthesized plausible
   inputs from ground_truth, consistent with the alert pattern class (all are
   scribe_read_proxy + ZippyDB cascade class, well-represented in other gold-set cases).

## Result

- `gold-set.json` version bumped: `2026-06-11-stable-inputs`
- All 60/60 cases have `input` fields
- eval-flow.js will now skip its Curate phase for gold-set cases with pre-populated inputs

## Impact on eval stability

Before: eval-flow re-curates 60 cases from ~270 archives each run → different case set →
iter4 baseline calibration 0.482 vs iter1 0.641 on different pools → cross-run Δ unreliable.

After: fixed 60-case test set → cross-run comparison reliable to ±~0.02 (estimated, assuming
~30% grader variance, per-case score is stable given same input).

**This is the prerequisite for Stage 3 batch mutation.** Without stable inputs, we cannot
confidently say a composite change of +0.008 (iter4 R19-STUS-exception) is real vs noise.

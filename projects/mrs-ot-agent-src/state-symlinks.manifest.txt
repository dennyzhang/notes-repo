# state-symlinks.manifest — canonical list of `~/.myclaw-ot-bot/` paths that should be symlinks into the notes repo
#
# Format: <local_path_relative_to_MYCLAW_HOME> -> <notes_path_relative_to_notes_root>
# Lines starting with `#` and blank lines are ignored.
#
# Read by: team_bot/bootstrap.sh `ensure_symlinks()` (idempotent).
#
# Lifecycle:
#   1. First-time migration: bootstrap moves the local file to notes path, replaces with symlink.
#   2. Fresh devserver reinstall: notes file already exists (via commit cloud / sl pull); bootstrap creates the symlink only.
#   3. Re-bootstrap on existing devserver: symlink already correct, no-op.
#   4. Conflict (local file AND notes file both exist as regular files): notes wins, local backed up with timestamp suffix, loud warning.
#
# What to put here vs. leave local:
#   PUT HERE: cron-state JSON, learnings.md — anything we want versioned/reviewable.
#   LEAVE LOCAL: myclaw.db (sqlite, runtime), *.sock (unix sockets), *.pid (daemon process), backups/ (ephemeral local), config.json (per-deployment).
#   See RULES.md §"Where state files live" for the policy.
#
# Maintained alongside RULES.md classification policy. When you add a new cron whose
# state should be versioned, add a row here and the next bootstrap picks it up.
#
# Updated 2026-05-17 after directory restructure (incidents/, auto-learnings/, human-input/).
